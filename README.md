# Framer archive (captured Nov 16, 2026)

Every image and video from the old Framer site at davybomb.com, downloaded at original upload quality
right before the Framer plan ended. This branch is a backup only; the live site is built on `main`.

- One folder per old page (`home/`, `boostra/`, `elation-print/`, ...).
- File names are Framer's random IDs. `manifest.json` maps each file to its old Framer URL and page.
- `davybomb-current-site-spec.md` describes every old page: copy, colors, fonts, interactions, and which image sits where.

When a page is rebuilt on `main`, copy the files it needs from here, give them readable names, and compress them for the web.
